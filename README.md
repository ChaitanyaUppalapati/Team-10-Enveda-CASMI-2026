# Team 10: Enveda CASMI 2026, Molecule ID from Mass Spectra

Kaggle competition: <https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra>

Given MS/MS spectra, rank candidate molecular structures. Scoring is **MRR@25**, matched on the first 14 characters of the InChIKey (RDKit 2026.03.3). The final pipeline runs as an **offline Kaggle notebook within 9 hours**.

## How integration works

Every model and baseline writes its predictions in one format:

```
outputs/scores/<model_id>/<split>.parquet    columns: query_id, inchikey14, score  (higher = better)
```

```python
from casmi.interfaces import write_scores, read_scores
write_scores(scores_df, model_id="fingerprint_mlp.arch1_mlp", split="val")
```

Rerankers, pooling, ensembles, B3, the scorer and the submission writer read only this format, so any model can be swapped in without code changes elsewhere.

```bash
pip install -e ".[all]"

python models/fingerprint_mlp/arch1_mlp/train.py --config models/fingerprint_mlp/arch1_mlp/config.yaml
python models/fingerprint_mlp/arch1_mlp/predict.py --split val
```
